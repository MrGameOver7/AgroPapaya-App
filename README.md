# AgroPapaya 

Aplicativo móvil offline para la detección temprana de enfermedades en hojas de papaya (como el Virus de la Mancha Anular y Oídio) mediante análisis de imágenes locales. Desarrollado para ayudar a pequeños agricultores en zonas rurales sin conexión a internet.

## Pasos para ejecutar la aplicación

Para correr este proyecto en tu entorno local, asegúrate de tener instalado [Node.js](https://nodejs.org/) y la aplicación **Expo Go** en tu dispositivo Android. Sigue estos pasos:

1. **Clonar el repositorio:**
   ```bash
   git clone [https://github.com/MrGameOver7/AgroPapaya-App.git](https://github.com/MrGameOver7/AgroPapaya-App.git)
   
2. **Ingresar al directorio del proyecto:**
      use el comando: cd AgroPapaya-App
   
4. **Instalar las dependencias:**
   use el comando: npm install

5. **Iniciar el servidor de desarrollo:**
   use el comando: npx expo start -c

6. **Ejecutar en el dispositivo:**
    Abre la aplicación Expo Go en tu celular Android y escanea el código QR que aparece en la terminal.
